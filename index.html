Grasp — step zero

Six concepts, one generation pass each, nothing else.

Grasp proposes generating interactive explainers and then mechanically verifying them. Every gate in that plan assumes the generated widget is good. Nobody checked. These six were produced in one pass with a plain prompt — no repair loop, no gates, no retries — because hand-tuned widgets prove nothing about a pipeline that cannot hand-tune.

The question is not whether they run. They run. It is: would you rather read these than a good blog post?

What the probe found result

Six for six on first-pass correctness. Zero repairs. Zero gate activations. Every concept with a reference implementation produced exact arithmetic immediately.

The softmax widget above is the finding. Its maths is flawless and would pass any oracle — but the “attention scores” feeding it come from a string hash, because real attention needs embeddings a one-shot generation does not have. A correctness gate passes it with full marks while it teaches something false.

The best of the six is Simpson’s paradox, whose value is entirely interaction design and which cannot be oracle-checked at all.

Conclusion: the defect rate lives in framing and presentation, not arithmetic.
